Welcome to PrettyWriter, a minimalist writing environment inspired by composing on analog typewriters. Typewriters are fun, tactile, dedicated writing tools. They inspire a desire to use them--a desire to write. It's just you, the machine, and the page. A typewriter engages your attention on your writing in a way a computer cannot. In the end, somehow, what you write feels more original. Or, at least, the writing experience was more special. 

A digital approximation of these phenomena is the goal of PrettyWriter.

KEYBOARD SHORTCUTS
═══════════════════════════════════════════════════════════════════════════════
PrettyWriter is designed to keep your fingers on the keys. You're not writing if you're mousing about! You'll find that several functions can only be accomplished with keyboard shortcuts.

ESSENTIAL COMMANDS
    ⌘S          Save current project
    ⌘K          Toggle Ideas panel
    ⌃ ⌃         Toggle Projects panel (double-tap Control)
    ⌘\          Toggle History panel
    ⌘E          Export menu
    ⌘F          Find (and replace) in the whole document; ⌘F again closes it
    ⌘G / ⌘⇧G    Next / previous match (Esc closes Find)
    ⌃⌘F         Fullscreen

WRITING ENVIRONMENT
    ⌘B          Change background image
    ⌘P          Show random writing prompt
    ⌃⌘F         Toggle fullscreen
    ⌘/          Toggle typing sound effects (FX)
    fn↑/↓       Page Up / Page Down (browser shortcut)

TEXT CONTROLS
    ⌘]          Next font
    ⌘[          Previous font
    ⌘.          Increase text size
    ⌘,          Decrease text size
    ⌘-click     Open a link

ENDNOTES
    ⌘⇧6         Add an endnote here (⌘^)
    ⌘J          Jump between an endnote number and its note

WRITING IN MARKDOWN
═══════════════════════════════════════════════════════════════════════════════
PrettyWriter renders Markdown as you type. Bold, italics, code and links take effect as soon as you type past the closing mark, and their symbols come back when your cursor touches them, so you can always edit them. Line symbols like # for headings and > for quotes hide when your cursor leaves the line. Your text is saved exactly as you typed it.

    `# Heading`         Heading (`##` and `###` for smaller)
    `**bold**`          Bold
    `_italic_`          Italic
    `~~strike~~`        Strikethrough
    `` `code` ``            Inline code
    `> quote`           Block quote
    `- item`            Bulleted list
    `---`               Divider line
    `[text](url)`       Link (⌘-click to open)
    `![alt](url)`       Image
    `text[^1]`          Endnote reference (see below)
    `[^1]: note`        The endnote itself

ENDNOTES
═══════════════════════════════════════════════════════════════════════════════
For longer essays, PrettyWriter keeps endnotes in standard Markdown, so they carry over to Obsidian and other Markdown tools.

Press ⌘⇧6 where a note belongs. A superscript number appears in your sentence, a new note line opens in the notes area at the end of the document, and your cursor moves there. Write the citation and any of your own comments, then press ⌘J to jump back and keep writing.

    ⌘⇧6         Add an endnote at the cursor
    ⌘J          Jump from a number to its note, or from a note back to the text
    Click       Click a superscript number to go to its note; click a note's
                number to go back

Notes are numbered in the order they appear in the essay. Add a note between 2 and 3 and it becomes the new 3: everything after it renumbers, and the new note takes its place in the list.

You can also type a reference by hand: `[^1]` in the text. As soon as you type the closing bracket, its note line appears in the notes section and your cursor stays where you're writing. The notes section takes care of itself: it starts at the end of the document with your first note, under a "Notes" divider that the editor draws (it isn't part of your text), and its notes always stay in the same order as their numbers. Move a sentence and its note moves with it.

Delete a reference and its note goes too if you never wrote anything in it. A note with writing in it is kept, shown faded at the end of the list, so a citation is never lost by accident.

Labels can be words, like `[^smith]`; they still display as numbers. When your cursor touches a reference, or sits on a note line, the raw Markdown shows so you can edit it. A number shown faded means a reference with no matching note, or a note nothing refers to.

PROJECTS PANEL (⌃ ⌃)
═══════════════════════════════════════════════════════════════════════════════
The Projects panel is a basic file and document saving structure to organize all your writing into separate projects and folders. Each project saves its own text, ideas and notes, background, and font settings.

BASIC USAGE
    N           Create new project
    F           Create new folder
    Enter       Open selected project
    R           Rename project/folder
    Delete      Delete project/folder
    ↑/↓         Navigate list
    ←/→         Collapse/open folder
    0           Jump to root level

HOW SAVING WORKS
    • Your text saves automatically as you type
    • ⌘S (panel closed): First time creates a new project with a name
    • ⌘S (panel open): Immediately saves to current project
    • Each project remembers: text, ideas & notes, background, font, and text size

HISTORY PANEL
──────────────────────────────
Functions like a browser history, time stamping your project history and saving it in order. Use it to quickly return to previous projects, if you find the workflow useful.
    ⌘          Open History panel

IDEAS & NOTES PANEL (⌘K)
═══════════════════════════════════════════════════════════════════════════════
A scratchpad for capturing thoughts, notes, and ideas as you write with minimal disruption to your flow. PrettyWriter promotes networked thinking to tap creativity.

BASIC USAGE
    • Type an idea in the input box
    • Enter: Save idea
    • Shift+Enter: Line break within input box (multi-line ideas)
    • Click any idea to edit it
    • Ideas save to the current project automatically

HASHTAGS
    • Use #hashtags anywhere in your ideas (e.g., "research scene #chapter3")
    • All hashtags appear as clickable pills above the input
    • Click a hashtag to filter ideas

TWO LISTS
    1. CURRENT PROJECT — Ideas for the project you're working on
    2. RECENT IDEAS — Ideas from other projects (click to jump to that project)
       Click ENDNOTES beside the label to swap this list for the current
       document's endnotes, in order; click a note to jump to it. Click
       RECENT IDEAS to switch back. PrettyWriter remembers your choice.

EXPORT (⌘E)
═══════════════════════════════════════════════════════════════════════════════

Save your writing to your computer in different formats:
    1  Plain text (.txt)
    2  Markdown (.md)
    3  HTML document (.html)

Files download with today's date automatically.

Note: As of right now, PrettyWriter utilizes local browser storage, not cloud storage. If you clear your browser cache you'll lose your work. Exporting is an important backup measure.

TIPS FOR FOCUSED WRITING
═══════════════════════════════════════════════════════════════════════════════

    1. Start with a prompt (⌘P) if you're stuck
    2. Toggle fullscreen (⌃⌘F) to eliminate distractions
    3. Use Ideas panel (⌘K) to capture tangential thoughts without losing focus
    4. Create project folders by theme (Journal, Fiction, Work, etc.)
    5. Typing sounds (⌘/) can help establish rhythm (or turn them off)
